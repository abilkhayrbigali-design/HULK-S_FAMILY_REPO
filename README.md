# HULK'S FAMILY — Conversation Quality Analytics

Прототип для хакатона Freedom Broker: оценка работы оператора по диалогу, объяснения с доказательствами, редактируемый чек-лист и пересмотр оценки через апелляцию.

**Статус на 7 ноября 2026 года:** подготовлены архитектура, контракты, план разработки и инструкции для четырёх участников. Приложение ещё не реализовано; команды запуска и результаты тестов появятся после выполнения задач из роадмапа.

## С чего начать участнику или AI-агенту

1. Прочитать [AGENTS.md](AGENTS.md).
2. Найти свою ветку и задачи в [роадмапе](docs/ROADMAP.md).
3. Прочитать [архитектуру](docs/ARCHITECTURE.md), [API-контракт](docs/API_CONTRACT.md) и [правила расчёта](docs/SCORING.md).
4. Использовать соответствующее задание из [инструкций для агентов](docs/AGENT_TASKS.md).
5. Обновлять роадмап вместе с реализацией, если изменились статус, зависимости, объём работы или техническое решение.

## Предлагаемый стек

- Интерфейс: React, TypeScript, Vite; результат сборки — HTML/CSS/JavaScript.
- Сервер: Python, FastAPI, Pydantic, SQLAlchemy, Alembic.
- Хранение: SQLite для одного экземпляра демонстрационного сервера.
- AI: OpenAI Responses API и Structured Outputs за заменяемым интерфейсом провайдера.
- Проверки: pytest, Playwright и отдельное сравнение оценок с ручной разметкой.
- Запуск: Docker Compose после реализации инфраструктуры.

Модель выбирается по проверке на RU/KZ/EN. Название модели в `.env.example` — начальный кандидат, а не обещание лучшей точности. Это выбор команды, а не требование организаторов.

## Данные и доступ

Проверенный DEV API содержит 65 диалогов: 60 чатов и 5 транскриптов звонков; 35 RU, 15 KZ, 15 EN. Для звонков есть ссылки на аудио. Эталонных оценок в полученном ответе нет.

Подписанная ссылка организаторов хранится только в локальном `.env` на сервере. Она не должна попадать в Git, интерфейс или логи. Пример названий настроек — [.env.example](.env.example); чтение этих настроек ещё предстоит реализовать.

В публичный репозиторий добавляются только собственные синтетические примеры. Исходные диалоги, аудио и ручная разметка хранятся в игнорируемом `data/private/`.

## Основания задания

План составлен по предоставленным `CQA_Hackathon_Student_Guide_v3 1.pdf`, `CQA_Chat_Quality_Checklist 1.pdf`, сообщению организаторов об отборе топ-50 и проверенному ответу DEV API. PDF `Data 2 (1) 1.pdf` содержит контекст о компании.

Основной ориентир отбора — близость AI-оценок к Ground Truth на 10 новых транскриптах. Дополнительно учитываются функциональность, удобство, корректность анализа новых данных и разнообразие архитектур. Формула рейтинга организаторов не опубликована в переданных материалах; наши внутренние метрики её не заменяют.
