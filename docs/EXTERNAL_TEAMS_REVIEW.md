## Поиск и уровни доказательств

Подтверждение кейса требует прямой ссылки на Freedom Broker/Data Challenge 2026 в документации проекта либо совпадения характерных условий задачи по нескольким независимым признакам, например исходные критерии, DEV и контрольная сдача. Общие слова CQA, «оценка качества» или схожий интерфейс недостаточны. Флаг GitHub `fork` проверен вместе с владельцем, названием команды, связями между репозиториями и содержимым. Одинаковый кейс и общий формат входа сами по себе не означают общий код.

Таблица различает **описано** (утверждение авторов), **код** (статическая проверка конкретного SHA), **проверено** (действительно выполненная в этом обзоре проверка). Найденные тесты и артефакты CI отмечаются отдельно от запущенных проверок. Чужой код, установщики, live API и модели не запускались. Содержимое чужих датасетов не переносилось.
